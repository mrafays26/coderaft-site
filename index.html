CodeRaft

Learn Python, one small step at a time.

CodeRaft is an iPhone app for complete beginners. Read a short explanation, write real Python, run it, and get friendly feedback on exactly what to fix — then keep going.

  • Four courses: Python Fundamentals, Python Projects, Object-Oriented Programming, and Blind 75: the classic coding interview problems by topic, each with a step-by-step solution.
  • Learn by doing: every lesson has coding exercises and a quick quiz.
  • Helpful feedback: common mistakes get specific advice, not just “wrong”.
  • A Playground to write and run any Python you like.
  • Private: no account, no ads, no tracking. Everything stays on your iPhone.

Support

Questions, bug reports or ideas? Open an issue on GitHub and include your iPhone model and iOS version if something isn't working.

Common questions

Does CodeRaft need an internet connection?
No. Lessons, exercises and the Playground all run on your iPhone.

Can I run any Python program?
CodeRaft runs the Python taught in its courses — variables, loops, functions, lists, dictionaries, classes and more. Things outside the courses (like import or input()) show a friendly note instead.

How do I start over?
Open the Progress tab and tap Reset Progress.
